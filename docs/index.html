Jelajah-In Progo

Dokumentasi WebGIS Pariwisata Kabupaten Kulon Progo.

Jelajah-In Progo merupakan aplikasi WebGIS yang menyajikan informasi dan persebaran destinasi wisata secara spasial. Dokumentasi ini menjelaskan struktur proyek, persiapan, serta cara menggunakan aplikasi.

Website: Buka Jelajah-In Progo

Installation

Untuk mempelajari atau mengembangkan proyek, siapkan browser modern dan editor kode seperti Visual Studio Code.

  1. Buka repository proyek di GitHub.
  2. Pilih Code, lalu Download ZIP.
  3. Ekstrak file proyek ke komputer.
  4. Buka folder proyek menggunakan editor kode.

Jika ingin mengembangkan proyek secara lokal, periksa kebutuhan library dan sumber data pada file program.

Quick Start

Cara paling cepat mengakses aplikasi adalah membuka tautan berikut:

https://aninditapawestria.github.io/jelajah-progo/

Tunggu hingga halaman selesai dimuat, kemudian gunakan menu yang tersedia untuk menjelajahi informasi wisata.

Configuration

Konfigurasi aplikasi mengikuti struktur HTML, CSS, JavaScript, serta data yang digunakan oleh proyek. Periksa referensi file pada kode sebelum mengubah lokasi atau format data. 

index.html
style.css
script.js
File data CSV

Nama file dan lokasi sumber data harus disesuaikan dengan isi repository yang sebenarnya.

Project Structure

  • index.html — struktur halaman utama.
  • style.css — aturan tampilan halaman.
  • script.js — logika dan interaksi aplikasi.
  • README.md — dokumentasi ringkas proyek.
  • docs/index.html — halaman dokumentasi teknis.
  • File CSV — data destinasi wisata jika digunakan oleh aplikasi.

Usage Guide

  1. Buka halaman utama Jelajah-In Progo.
  2. Pilih menu peta untuk melihat persebaran destinasi wisata.
  3. Jelajahi informasi destinasi yang disediakan aplikasi.
  4. Gunakan menu navigasi untuk berpindah halaman.

Detail interaksi dan informasi yang tersedia mengikuti implementasi website.
